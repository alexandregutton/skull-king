# Skull King · Carnet de bord

Compteur de points pour le jeu de plis Skull King, en web app installable (iPhone : Safari → Partager → « Sur l'écran d'accueil »).

- Scores Skull King et Rascal (avec Boulet de canon), bonus, Butin, Kraken/Baleine, pouvoirs des pirates
- Sauvegarde automatique sur l'appareil, export/import JSON
- Fonctionne hors ligne (service worker)

Fichiers statiques, aucune dépendance : `index.html`, `manifest.webmanifest`, `sw.js`, `icons/`.
